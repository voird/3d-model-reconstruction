# Программная система восстановления трехмерных моделей по растровым изображениям

## Описание проекта
Проект представляет собой программную систему для восстановления 3D-моделей на основе растровых изображений с использованием методов машинного обучения и компьютерного зрения.

## Основные возможности
- загрузка изображений;
- обработка изображений;
- реконструкция трехмерной модели;
- визуализация результатов;
- сохранение полученных моделей.

## Используемые технологии
- Python
- PyTorch
- OpenCV
- Trimesh
- PyRender
- Django
- PostgreSQL

## Цель проекта
Разработка системы автоматизированного восстановления трехмерных объектов по изображениям.
